✓ 它會做的事

  • 新增 Google 日曆活動（有時間的、整天的）
  • 查某一天或某段時間的行程
  • 文字：傳一段資訊，收錄到試算表的「記錄」分頁
  • 連結：訊息裡有網址，連同網頁標題收錄到「連結」分頁
  • 筆記：開頭打「筆記」，整段收錄到「筆記」分頁
  • 照片、檔案：存到雲端硬碟的「AI 秘書檔案」資料夾，並在「檔案」分頁留下連結
  • 待辦事項：「待辦：打電話給王主任」加入清單，「待辦」看清單，「完成 1」打勾
  • 記帳：「午餐 120」「加油 1250」自動分類記到「記帳」分頁，「查帳」看本月統計
  • 用關鍵字查之前收錄的記錄、筆記、連結
  • 其他問題照常聊天回答

! 使用前要知道

  • 只有名單上的人能用，其他人傳訊息只會看到自己的 ID
  • 訊息會經過 Gemini，不要傳病人或個案的可辨識資料
  • 每則訊息是獨立的，它不記得上一句說了什麼
  • 一則訊息大約要等 3～8 秒
  • 目前不能修改或刪除，要改請直接到日曆、試算表或雲端硬碟改
  • 問句會當成聊天回答、不會收錄；想確定收錄，開頭加「記一下」或「筆記」
  • Telegram 的檔案上限 20MB；LINE 的照片、檔案過一段時間會過期，要收錄請盡快傳
第 1 步 / 共 5 步

另外開一個 Apps Script 專案

秘書版要用 Apps Script 當中繼站，因為它可以直接操作你自己的 Google 日曆和試算表。請新開一個專案，不要蓋掉原本聊天機器人的程式。

  1. 開啟 Apps Script ↗，按 新專案，名稱改成「AI 秘書」。
  2. 按左邊的 ⚙ 專案設定，確認「時區」是 (GMT+08:00) 台北。時區不對，記到行事曆的時間會跑掉。
  3. 在下方小工具填入 Gemini 金鑰和你要用的平台權杖（LINE 或 Telegram 擇一即可），按 複製程式碼。「允許使用的 ID」先留空。
  4. 回到編輯器，把原本的內容全部刪掉、貼上、儲存。

第 2 步 / 共 5 步
執行測試並授權
第一次要讓程式取得操作你的日曆和試算表的許可。
  1. 上方函式選單選 testSecretary，按 ▶ 執行。
  2. 出現授權視窗：審查權限 → 選你的帳號 → 進階 → 前往（不安全） → 允許。這次會多要求「日曆」「試算表」和「雲端硬碟」的權限。
  3. 執行記錄會出現五行：記了一筆測試資料、雲端硬碟資料夾網址、今天的行事曆、AI 把「明天下午三點跟王主任開會」變成的 JSON、試算表網址。
  4. 如果其中一行是「402 … prepayment credits are depleted」：金鑰的專案開了付費但沒有儲值金，解法在基本版最下面的常見問題。
  5. 打開那個試算表網址，確認有「記錄、連結、筆記、檔案、待辦、記帳」六個分頁，「記錄」裡有一筆「秘書版安裝成功」。
第 3 步 / 共 5 步
部署並接上聊天平台
和基本版一樣，把程式變成網址，再告訴 LINE 或 Telegram。
  1. 部署 → 新增部署作業 → ⚙ 選 網頁應用程式 → 執行身分「我」、存取權「所有人」→ 部署，複製 /exec 網址。
  2. LINE：到 LINE Developers 的 Messaging API 分頁，把 Webhook URL 換成這個新網址。
  3. Telegram：把 token 和網址填到下方小工具，按 開啟設定網址。
  4. 提醒：一個機器人同時只能接一個中繼站。接上秘書版後，原本的聊天版就不會再回覆；秘書版本身也能聊天。

第 4 步 / 共 5 步
把自己加進允許名單
機器人是用你的 Google 帳號做事，所以一定要鎖定只有你能用。
  1. 用手機傳任何一句話給機器人，它會回「你的 ID 是：……」。
  2. 把那串 ID 複製起來，貼到下方小工具的「允許使用的 ID」，重新複製程式碼、貼上、儲存。（或直接在編輯器改：ID 前後一定要加單引號，寫成 var ALLOWED_USERS = ['你的ID'];。少了引號，執行時會出現「… is not defined」。）
  3. 部署 → 管理部署作業 → ✏️ 編輯 → 版本選 新版本 → 部署。
  4. 再傳一句話，機器人不再回 ID，就代表設定好了。
第 5 步 / 共 5 步
開始使用
直接用平常說話的方式交代事情。
  1. 記行事曆：「明天下午三點跟王主任開會，地點在三樓會議室」「11 月 30 日車子要保養」。
  2. 查行事曆：「我明天有什麼事？」「這週的行程」。
  3. 收錄文字：「影印機的維修電話是 02-1234-5678」「記帳：午餐 120 元」。
  4. 收錄連結：直接貼上網址，後面可以加一句說明，例如「https://… 下次上課用」。
  5. 收錄筆記：開頭打「筆記」再接內容，可以換行寫很多行。
  6. 收錄照片、檔案：直接傳給機器人，它會回你雲端硬碟的連結。
  7. 待辦事項：「待辦：打電話給王主任」「記得週五前交報告」加入；傳「待辦」看清單；做完傳「完成 1」或「報告交了」。
  8. 記帳：「午餐 120」「昨天加油 1250」「領薪水 45000」；傳「查帳」看本月支出和分類，也可以問「十月花了多少」。
  9. 查資料：「幫我找影印機的記錄」「最近記了什麼？」會一起找記錄、筆記和連結。
  10. 機器人回覆的內容是程式實際寫進去的結果，可以直接對照日曆和試算表確認。

最省力的做法：請 ChatGPT 或 Gemini 幫你改
把整份程式碼貼給 AI，加上下面這段話。貼之前先把最上面的金鑰和權杖改成 XXXX，改好拿回來再填回去。


這是我的 Google Apps Script 聊天機器人程式（接 LINE／Telegram，用 Gemini 判斷要做什麼，資料寫進 Google 試算表）。

請幫我加一個新功能：【用一兩句話描述。例如：記錄每天的血壓，我會說「血壓 128/82」；我說「血壓記錄」時，列出最近 7 筆】

請照程式裡現有的寫法做這四件事：
1. 在 TABS 加一個分頁和欄位
2. 寫新的函式（參考 addRecord、listRecords 的寫法）
3. 在 askPlan 的提示文字加一條新的 JSON 指令和使用時機
4. 在 handle 加對應的 if

限制：不要改動其他功能，不要改最上面「只要改這一區」的內容，只用 Google Apps Script 內建的服務，註解用繁體中文。
最後請給我「完整的、可以整份貼上」的程式碼，並列出你改了哪幾個地方。

! 常見卡關
  • AI 給的程式碼不完整（中間寫「…其餘不變」）：請它「給我完整程式碼，不要省略」
  • 貼回去後出現紅字錯誤：把錯誤訊息整段貼回給 AI，請它修
  • 改壞了想回復：Apps Script 左側「專案記錄」（時鐘圖示）可以還原舊版本，或重新從本頁複製
  • 忘了部署新版本：編輯器裡測試正常，但 LINE 上還是舊的
  • 金鑰貼給了 AI：到 AI Studio 把那把金鑰刪掉，重新建立一把
