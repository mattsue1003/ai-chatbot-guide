進階 · Gemini × Apps Script × Google 試算表知識庫

衛教小幫手機器人

給民眾用的糖尿病衛教 LINE 機器人：民眾打字發問，它只根據你放在試算表裡的衛教資料回答，每則回答都附上資料來源。內容、語氣、提醒文字都可以自己調整。需要先完成 基本版，手上已經有 Gemini 金鑰。約 30 分鐘。

← 回基本版教學AI 秘書版

一個問題是怎麼被回答的

1民眾在 LINE 發問「低血糖怎麼辦？」
→
2先擋緊急狀況有「叫不醒、胸痛」等字，直接請對方撥 119
→
3查你的知識庫從試算表挑出最相關的幾則衛教資料
→
4Gemini 只根據資料回答每個重點標出用了哪一則；資料沒有就說找不到
→
5程式附上來源來源名稱和網址從試算表帶出，再加上提醒文字

這種做法叫 RAG（先查資料再回答）。AI 負責把資料講成好懂的話，內容和出處由你的知識庫決定。

✓ 它會做的事

  • 回答知識庫裡有的衛教問題，並附資料來源（名稱與網址）
  • 知識庫沒有的，明說找不到，請對方問醫療團隊
  • 緊急關鍵字直接回就醫提醒
  • 把民眾的提問記到試算表（不記是誰問的），讓你知道該補什麼
  • 一律用繁體中文回覆

! 使用前要知道

  • 示範資料是教學用的摘要，不是正式指引。給民眾用之前一定要換成你們單位審核過的內容
  • 它不能診斷、不能調整用藥，遇到這類問題會請對方找醫療團隊
  • 每則訊息是獨立的，它不記得上一句
  • 只看得懂文字，照片和語音不處理
  • 這一版只接 LINE
第 1 步 / 共 7 步

建立知識庫試算表

衛教內容放在你自己的 Google 試算表，一列一個主題。以後要新增、修改衛教內容，只要改試算表，不用碰程式。

  1. 開一個新的 Google 試算表，改名為 衛教知識庫。
    開啟新的試算表 ↗
  2. 上方選單點 擴充功能 → Apps Script，會開啟寫程式的分頁。把左上角的專案名稱改成「衛教小幫手」。
  3. 一定要從試算表的「擴充功能」進去。直接到 script.google.com 開新專案，程式會找不到知識庫。
  4. 另外準備一個新的 LINE 官方帳號給民眾加好友（照基本版的第 2 到 4 步做：建立帳號、啟用 Messaging API、取得 Channel access token）。不要用你私人筆記或秘書用的那個帳號。
第 2 步 / 共 7 步

產生並貼上程式碼

在下面填好金鑰和小幫手的名字，整份複製貼到 Apps Script。

  1. 在下方小工具填入 Gemini 金鑰、LINE 權杖、小幫手的名字和你的單位名稱。
  2. 按 複製程式碼，回到 Apps Script 編輯器，把原本的內容全部刪掉、貼上，按 Ctrl＋S（Mac 用 ⌘＋S）儲存。
  3. 程式碼最上面「只要改這一區」是之後可以自由調整的地方，現在先不用改。

第 3 步 / 共 7 步
執行 setupKB 並授權
讓程式建立「知識庫」和「提問記錄」兩個工作表，放進 8 則示範資料，順便測試金鑰。
  1. 上方函式選單選 setupKB，按 ▶ 執行。
  2. 出現授權視窗：審查權限 → 選你的帳號 → 進階 → 前往「衛教小幫手」（不安全） → 允許。這是你自己的程式，所以 Google 會提示未經驗證。
  3. 執行記錄出現三行：已放進 8 則示範資料、知識庫目前有 8 則可以用的資料、Gemini 測試：……。
  4. 回試算表分頁，會看到「知識庫」工作表：編號、主題、內容、來源名稱、來源網址。
  5. 如果 Gemini 測試那一行出現「402 … 儲值金用完了」：解法在基本版最下面的常見問題。
第 4 步 / 共 7 步
不用開 LINE，先看它怎麼回答
在編輯器裡直接測三種情況：知識庫有的、知識庫沒有的、緊急狀況。
  1. 函式選單選 testAsk，按 ▶ 執行。
  2. 第一題「低血糖的時候要怎麼辦？」：回答裡每個重點後面有 [2] 這種編號，最後列出「資料來源」和提醒。
  3. 第二題「颱風天要準備什麼？」：知識庫沒有，所以回「在我手邊的衛教資料裡找不到」。它不會自己編答案。
  4. 第三題「我爸爸叫不醒」：有緊急關鍵字，程式不問 AI，直接請對方撥 119。
  5. 回試算表看「提問記錄」工作表，三個問題和回答都記下來了。


✓ 這個小幫手的三個安全設計
  • 只根據知識庫回答：AI 被要求只能用你提供的衛教資料
  • 沒有出處就不回答：資料來源是程式從試算表帶出來的，不是 AI 寫的；AI 的回答如果沒有標出用了哪一則，整則不送出
  • 緊急狀況不交給 AI：出現「叫不醒、胸痛、想不開」這類字，直接回固定的就醫提醒
第 5 步 / 共 7 步
部署並接上 LINE
把程式變成網址，填到新官方帳號的 Webhook。
  1. 部署 → 新增部署作業 → ⚙ 選 網頁應用程式 → 執行身分「我」、存取權「所有人」→ 部署，複製 /exec 網址。
  2. 到 LINE Developers → 你的新官方帳號 → Messaging API 分頁，Webhook URL 貼上網址 → Update，把 Use webhook 打開。
  3. 同一頁的 Auto-reply messages 按 Edit，把自動回應訊息關閉。「加入好友的歡迎訊息」可以留著，建議寫上「請勿傳送個人資料，緊急狀況請撥 119」。
  4. 之後只要改過程式碼，都要「部署 → 管理部署作業 → ✏️ 編輯 → 版本選新版本 → 部署」。只改試算表的知識庫不用重新部署，馬上生效。
第 6 步 / 共 7 步
用手機驗收
加好友，實際問幾個問題。
  1. 用手機 LINE 掃官方帳號的 QR code 加好友。
  2. 傳「你好」：它會自我介紹，並列出可以問的主題。
  3. 問一個知識庫有的問題，例如「糖尿病可以吃水果嗎」「腳要怎麼保養」。確認回答最後有「資料來源」。
  4. 問一個知識庫沒有的問題，確認它回「找不到」而不是亂答。
  5. 問「可以幫我調藥嗎」：它應該請你詢問醫療團隊。
  6. 回試算表看「提問記錄」：之後民眾問了什麼、哪些題目回「找不到」，都在這裡。回「找不到」最多的題目，就是知識庫該補的內容。
第 7 步 / 共 7 步
換成你們單位的衛教內容
示範資料只是教學用的摘要。要給民眾用，知識庫一定要換成你們單位審核過的正式內容，並填上真正的來源。
  1. 打開「知識庫」工作表，直接修改或新增列。一列一個主題，「內容」寫 80 到 200 個字。
  2. 來源名稱一定要填（例如「○○醫院糖尿病衛教單張：低血糖的處理，2025 年版」）。沒填來源名稱的那一列，小幫手不會拿來回答。
  3. 來源網址有就填，民眾會在回答最後看到，可以點進去看原文。
  4. 「編號」不能重複，用 1、2、3… 往下編就好。回答裡的 [2] 就是這個編號。
  5. 想換主題（高血壓、長照、失智照顧）：把程式碼最上面的 TOPIC 改掉，知識庫換成那個主題的內容。
  6. 最省力的做法：按下方 複製這段話，連同衛教單張的文字貼給 ChatGPT 或 Gemini，請它整理成表格，再貼進試算表。貼進去之前，請逐列對照原文確認數字沒有錯。

! 開放給民眾之前
  • 知識庫的每一列都請專業人員看過，來源是正式、查得到的文件
  • 自己先把常見問題問過一輪，看回答有沒有偏離原文
  • 在官方帳號的歡迎訊息和圖文選單寫清楚：這是衛教資訊，不是看診；不要傳個人資料；緊急請撥 119
  • 問答內容會送到 Gemini。免費方案的內容可能被 Google 用來改善產品，所以要提醒民眾不要傳姓名、身分證字號、病歷號
  • 定期看「提問記錄」，補知識庫、修正不清楚的內容


✓ 額度
  • LINE 機器人「回覆」訊息不算則數，免費方案就能用
  • 每個問題呼叫 Gemini 1 次；每人每小時上限由 MAX_PER_HOUR 控制
  • 使用人數多、免費額度不夠時，再考慮 Gemini 的付費方案

自由調整：讓它變成你的小幫手
程式碼最上面「只要改這一區」的每一行都可以改。改完記得部署新版本。
  1. 名字和單位：BOT_NAME、ORG_NAME，會出現在自我介紹。
  2. 說話方式：TONE。例如改成「對象是長輩，句子要短，一次只講三個重點」。
  3. 每則回答最後的提醒：DISCLAIMER。可以加上衛教室電話和服務時間。
  4. 找不到答案時的回覆：NOT_FOUND。可以加上「請撥打衛教專線 ○○○」。
  5. 緊急關鍵字和回覆：EMERGENCY_WORDS、EMERGENCY_REPLY。可以加上你們科別該注意的字。
  6. 每人每小時的題數：MAX_PER_HOUR。要不要記錄提問：LOG_QUESTIONS。
  7. 想加新功能（例如問「掛號」直接回網址）：把程式碼貼給 ChatGPT 或 Gemini，加上下面這段話。貼之前先把金鑰和權杖改成 XXXX。

✓ 帶學員做的建議順序
  • 先讓每個人用示範資料裝好、能問答
  • 每人帶一份自己單位的衛教單張，請 AI 整理成知識庫，逐列核對
  • 改 TONE、DISCLAIMER，做出自己單位的口吻
  • 互相加好友出題，找出「答錯」和「找不到」的題目，回去補知識庫


! 常見卡關
  • 回答沒有附來源、一直回「找不到」：知識庫那一列的「來源名稱」是空的，或 AI 沒有標編號；先執行 testAsk 看結果
  • 改了程式碼沒有變：忘了部署新版本
  • 改了知識庫沒有變：確認改的是「知識庫」工作表，而且編號沒有重複
  • 完全沒反應：存取權要選「所有人」，Webhook 要填 /exec 網址並打開 Use webhook
  • 金鑰貼給了 AI：到 AI Studio 把那把金鑰刪掉，重新建立一把
